# BB1 – Gym Membership Management Portal

MERN stack starter skeleton for the Gym Membership Management Portal.

## Purpose

This repository intentionally contains only the basic project structure and starter files. It does **not** implement the client requirements.

Use the Project Requirement Document as the source of truth and build the application from this starting point.

## Stack

- MongoDB
- Express.js
- React.js
- Node.js

## Suggested structure

```text
BB1/
├── client/        # React frontend
├── server/        # Node.js + Express backend
├── .gitignore
└── README.md
```

## Getting started

1. Clone the repository.
2. Install dependencies from the frontend and backend package files.
3. Create your environment variables using the provided examples.
4. Start implementing the requirements from the Project Requirement Document.

No business logic, database schema, API implementation, authentication implementation, role handling, CRUD implementation, or finished UI is provided intentionally.
